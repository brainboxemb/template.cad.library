# template.cad.library

Self-contained CAD library repository template derived from template.cad.model-project.

- `modules/`: internal CI capabilities, each with its own configuration and tests.
- `site/`: Hugo/Hextra documentation.
- `forge/` and `examples/`: planned library source and verification owners.

Stable source is `main`, development source is `dev`. See [manual](docs/manual.md) and [plan](docs/plan.md).
